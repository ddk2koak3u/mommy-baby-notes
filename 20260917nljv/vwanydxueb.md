# 春季宝宝过敏，如何吃住行全在这儿啦~

> 更新时间：2026-09-17 (UTC+8)

又到一年换季时，很多过敏宝宝开始有了各种不同的反应。今天，**徐州市妇幼保健院儿童营养门诊国家首批免试注册营养师盛志华**来跟大家谈谈宝宝过敏。 

不能因为食物过敏就“因噎废食”  

盛志华主任说，过敏是当机体受到生理剂量的过敏原刺激后，出现异于常人的生理功能紊乱或组织细胞损伤的反应。随着疾病谱的转变，过敏性疾病已成为21世纪常见疾病之一，影响了全球约25%的人群，不仅影响患儿的生活质量，甚至危及生命，并给社会带来沉重的经济负担。

**过敏性疾病包括：****食物过敏、特应性皮炎、过敏性鼻炎和过敏性哮喘等。**过敏反应有的较轻微，有的比较严重，有的则有致命危险。对于出现过敏反应的孩子，医生一般都会首先查出是哪种物质引起的过敏，然后再建议回避过敏原。盛志华主任强调：“要回避过敏原，但不能因噎废食。”    

比如，牛奶蛋白过敏，是婴幼儿常见的食物过敏性疾病，可以说，在婴幼儿时期，90%的食物过敏与牛奶、鸡蛋、坚果、海鲜、大豆、热带水果等8种食物有关。但同时，牛奶也是婴幼儿获取营养最主要的食物，该怎么办？家长应该正确对待及引起重视。

“**当宝宝出现持续腹泻腹泻、呕吐、无故拒奶等症状时，需要及时就医，确诊是否为牛奶蛋白过敏，如不及时治疗和干预，会影响宝宝近期及远期生长发育。**”     

当确诊为牛奶蛋白过敏时，为了保证孩子生长所需的营养，必须要使用替代性食物，可根据过敏程度等食用治疗性奶粉。如果孩子是鸡蛋过敏，则可以用30克的肉来补充其蛋白，同时注意其他营养素的摄入均衡。

     

盛志华主任说，引起宝宝过敏的原因很多，有些是因为遗传因素，有些是肠胃发育问题及环境等等因所致素。大多食物过敏80%可以在2岁以后得到缓解，但有些可能会伴随终身。 儿童过敏现象，在婴儿期主要以食物过敏为主，多出现皮疹、胃肠道随着时间的推移则会对过敏物质发生改变。 

春天过敏宝宝的“衣食住行”应该注意哪些？盛志华老师从衣食住行四个方面进行了介绍。

穿 衣

- 对于湿疹宝宝，尽量穿纯棉衣物，因为穿纯棉衣物能为宝宝提供最柔软的保护

- 同时应避免过度染色的衣服，因为大红、大绿的染色衣物，容易造成染色物的存留，淡色衣物是更佳选择；

- 避免衣服上有特殊花纹或有尖锐物，衣服上带有特殊花纹，容易在破擦时出现皮肤破溃，造成感染，在过敏急性期，还应避免着皮毛发热衣物。

饮 食

对于过敏宝宝，家长应该听从医生的话，严格回避需要回避的过敏原，不要总是“不死心”的尝试。在医生或营养师的指导下选择治疗奶粉，科学搭配宝宝的饮食，将“眼光”开阔起来，其实宝宝的饮食不单单是鸡蛋和虾。 

住

- 家庭中常见的过敏原：尘螨、霉菌、动物毛发、家具油漆；

- 除螨不是简单的卫生清洁，应该勤打扫，不留死角；

- 室内湿度保持在50%—55%，多通风；

- 保持浴室干燥，赶走霉菌，挑选适合的窗帘，孩子的衣物多晾晒；

- 孩子睡眠不开小夜灯；

- 不让孩子接触二手烟，尽量使用无毒建材。

出 行

- 多带孩子去视野开阔，空气清新的环境玩耍。

- 上午9—10点，有呼吸道疾病的患儿应减少户外运动，此时户外花粉浓度为一天中最高峰。

- 带过敏宝宝出行应注意： 正在过敏的宝宝出发前，用一次过敏抗过敏药物，到达时可以再用一次； 

- 常年鼻炎或者鼻窦炎的患儿，最好带上鼻炎药物备用； 

- 对于有哮喘的宝宝止喘药是必不可少的；

- 带上退烧药，益生菌口服补液，盐开塞露及抗菌药物

- 如果还带孩子游泳，先使用抗过敏药，游泳后一定要清洗鼻子

- 到达后48小时，宝宝就可以食用当地食材。
总之，盛主任提醒，敏宝只要及时到正规医院找专业医师及营养师就诊，定期复查，在发病早期进行正确干预，一定能较好的健康成长！
